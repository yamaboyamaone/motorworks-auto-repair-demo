# MotorWorks Garage — Auto Repair Website Concept

A responsive single-page website concept for a fictional auto repair business. Created as a portfolio demo.

## Run locally
Open `index.html` in a modern browser.

## Deploy
1. Upload this folder to a new GitHub repository.
2. Import the repository into Vercel, or deploy the static `index.html` directly with Netlify Drop.
3. No build command is required.

## Important before client delivery
- This is a fictional concept, not a real client project.
- Replace sample business name, phone, email, address, hours, and illustrative testimonials.
- The quote form is a front-end demo only; it does not send/store submissions. Connect a secure form backend or form service for a real client.
- Images are loaded from Unsplash and require internet access.
